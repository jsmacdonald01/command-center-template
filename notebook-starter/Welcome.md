# Welcome

This is your Command Center notebook. Command Center made it for you and
shows it on the Workshop page. To change a note, click it there, then
**Edit in Obsidian**.

Write anything here — the agent and Claude can read it too.

The `Handoffs` folder is how Claude Code remembers your Command Center
between sessions:

- [[Next Session]] — read first by every Claude Code session
- [[Current State]] — what is true about your Command Center right now
- [[Decisions]] — why things are the way they are
- [[Ideas]] — things you might want to add some day
